Como funciona

Quatro passos, sempre os mesmos

Você diz o quê. Ele cuida de onde e como.

1

Identifica a área

Negócio, produto, arquitetura, dados, API, tela, segurança ou infra. Se o pedido for ambíguo, ele pergunta. Se misturar áreas, divide.

2

Lê o que já foi decidido

Só os documentos que aquela área exige. É isso que impede uma página nova de contradizer uma antiga.

3

Escreve no modelo certo

Se o pedido contradiz uma regra registrada, ele aponta a contradição em vez de escrever.

4

Registra e sincroniza

Anota a mudança no histórico da área e atualiza a camada que a IA consulta.

Instalar

Dois comandos e está pronto

Abra o Claude Code na pasta do projeto. As pastas de documentação aparecem no primeiro pedido.

1/plugin marketplace add davidcromianski-dev/living-brain
2/plugin install living-brain@living-brain
3/reload-plugins

Confira com /plugin. Se living-brain aparece habilitado, é só pedir.

Faça commit de .claude/settings.json. Quem clonar o projeto recebe o plugin.

{
  "extraKnownMarketplaces": {
    "living-brain": {
      "source": { "source": "github", "repo": "davidcromianski-dev/living-brain", "ref": "v0.1.1" }
    }
  },
  "enabledPlugins": { "living-brain@living-brain": true }
}
.claude/settings.json
Só no Claude Code.Se o comando /plugin não existe onde você digita, você está no chat comum do claude.ai, que não carrega plugins.
Dúvidas

Perguntas frequentes

Preciso saber programar?
Não para usar. Você abre o Claude Code numa pasta e cola os comandos de instalação. Depois disso, os pedidos são em linguagem natural.
Onde ficam os documentos?
No seu próprio repositório. O Living Brain não guarda, não copia e não envia nada do seu produto. Por padrão as pastas ficam na raiz, ou numa pasta que você escolher com .living-brain.yml.
Em que idioma os documentos são escritos?
Você conversa em português, mas hoje o plugin escreve os arquivos em inglês, para manter a documentação consistente.
Quanto custa?
O plugin é gratuito e de código aberto, sob a licença MIT. O uso do Claude Code segue o seu plano do Claude.
Preciso instalar mais alguma coisa?
Não. Opcionalmente, o plugin superpowers permite delegar documentos longos a subagentes. O Living Brain funciona sem ele.

Ficou com alguma dúvida?

Abra no GitHub. A resposta fica pública e ajuda quem tiver a mesma pergunta depois. Os botões abrem um modelo já preenchido.
